# OpenTenBase 数据库图解卡片

用一张图、一个例子和可核对的项目资料，解释数据库概念。

| 概念 | 适合了解的问题 |
| --- | --- |
| [分布式 JOIN 中的数据重分布](join-redistribution.zh-CN.md) | 为什么连接两张表，有时要先跨节点传输数据？ |

卡片同时提供 PNG 展示图、可编辑 SVG 和 Mermaid 流程图源码。示例数据用于解释概念，具体执行方案应结合实际版本、表定义和 `EXPLAIN` 判断。
