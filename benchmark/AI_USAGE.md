# AI 使用策略报告

## 使用范围

- 协助阅读 OpenTenBase 架构、数据分布、pgbench 和监控文档。
- 协助设计 5,000,000 行测试表和五类测试脚本。
- 检查 SQL 变量范围是否与实际数据一致。
- 在用户授权后执行本地基准测试并记录工具输出。
- 根据 pgbench、行数核对和节点分布整理初步分析。

## 人工可复核内容

- 所有 SQL 和测试脚本均保存在 `benchmark/` 中。
- 5,000,000 行数据由 `generate_series` 实际装载，不是 AI 估算。
- 写入测试前后均检查行数，并恢复被测试过程影响的基线订单。
- 性能数字来自 2026-07-21 的本地实际运行。

## AI 没有做的事情

- 没有生成或伪造性能数字。
- 没有把单机、数据大多在内存中的结果描述成生产容量。
- 没有修改 OpenTenBase 内核参数来获得更高结果。
- 没有发布 GitHub Discussion；发布前仍需用户检查公开内容。

## 风险控制

- 数据库在原有 `benchmark_100k` 上直接重建并改名为 `database`，没有同时保留两份大数据库。
- 写入测试固定为 100 个事务，测试后恢复 5,000,000 行基线。
- 正式测试脚本使用 `-n`，避免 pgbench 操作不存在的标准表。
- 只通过 CN 执行业务测试，并在报告中注明单机部署限制。
