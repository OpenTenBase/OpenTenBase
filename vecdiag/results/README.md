## 怎么读一份证据

每个 run 目录的构成一致：

```
<run>/            一个实验一轮的原始产物
├── *.csv / *.tsv  结构化结果（可重算）
├── stderr/        报错与 NOTICE 原文（一字不改，K7 门禁）
├── SHA256SUMS     本目录全部文件的校验和
└── env.txt        （部分目录）产出时刻的环境快照
```

## 顶层散文件去哪了

原 `results/` 顶层的 13 个散文件（abi_const_final.csv、stage_weights_*.csv、
param_*.csv、eta_accuracy.csv、sift_sha256*.txt 等）是**数据库最终状态的导出**，
已收进 `centos7-20260826/index/`——它们全部产自第一台机器。Rocky 机器的
同类导出在 `rocky-20260827/` 各 run 内。

## 引用规则（写文档/报告时）

引用证据一律写**仓库相对路径**（如 `results/centos7-20260826/m1-r3-20260826/results.tsv`），
不写绝对路径、不写开发服务器地址。被取代的中间轮在 `centos7-20260826/archive/`
里保留（保留原因见该目录说明），正文只引用最终轮。
