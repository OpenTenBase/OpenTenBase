## archive/ 里是什么（为什么留着）

- `m1-20260826/`：M1 首轮，harness 11 PASS/9 FAIL——**这轮抓出了三个真实模型缺陷**
  （`sum(bigint)` 返回 numeric 使阈值偏 1 kB、`heap==NULL` 误读为 unlogged、
  reltuples 估计值放大误差）。失败本身是证据，删掉就说不清模型是怎么被修正的。
- `m1-r2-20260826/`：修缺陷后的第二轮，矩阵仍有边界用例问题；`m1-r3` 是最终轮，
  **正文与报告只引用 m1-r3**。
